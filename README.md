# agenda-camila-valadares
Agenda profissional web independente para Camila Valadares

## Agendamentos recorrentes
O formulário permite repetir um atendimento semanalmente, a cada duas semanas ou mensalmente, entre 2 e 52 ocorrências. As séries são gravadas em uma única transação no banco D1, preservando os agendamentos individuais e impedindo gravação parcial quando houver conflito.
